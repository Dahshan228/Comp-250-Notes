# Note 8: Anthropic’s Advice for Defenders

**Quotation:** “A fundamental change has occurred in cybersecurity. We [Anthropic] advise security teams to experiment with applying AI for defense in areas like Security Operations Center automation, threat detection, vulnerability assessment, and incident response” (Anthropic 2025, under “Cybersecurity Implications”).

**Commentary:** The thing I noticed about this list is what’s missing from it.
Everything Anthropic suggests is about noticing a problem, like monitoring networks, detecting attacks, scanning for weak spots, and responding after a break-in.
Nothing on the list is about actually installing the fix, which is the slowest part of the patch window and the part our storyboard says still moves at human speed.
Detecting an attack faster helps, but the defender is still reacting after the attacker has already moved.
The wording also stood out to me.
The attackers in this same report were already using AI to run most of a real campaign, but defenders are only told to “experiment.”
That difference between attackers using AI for real and defenders just trying it out is basically the imbalance our claim is about.
If AI is going to help defenders actually close the window, someone needs to show it testing and rolling out patches safely, and none of my sources do that yet.
That’s the evidence I most need to look for next.

**Subject terms:** threat detection; patch deployment; patch window; offense–defense balance
