# Note 8: Anthropic’s Advice for Defenders

**Quotation:** “A fundamental change has occurred in cybersecurity. We [Anthropic] advise security teams to experiment with applying AI for defense in areas like Security Operations Center automation, threat detection, vulnerability assessment, and incident response” (Anthropic 2025, under “Cybersecurity Implications”).

**Commentary:** What stands out to me is what’s missing from this list.
Everything Anthropic suggests is about noticing a problem, like detecting attacks, scanning for weak spots, and responding after a break-in.
Nothing is about actually installing the fix, which is the slowest part of the patch window.
The wording stood out too.
The attackers in this same report were already using AI to run a real campaign, but defenders are only told to “experiment,” and that gap is basically the imbalance our claim is about.
None of my sources show AI testing and rolling out patches safely, so that’s the evidence I most need to find next.

**Subject terms:** threat detection; patch deployment; patch window; offense–defense balance
