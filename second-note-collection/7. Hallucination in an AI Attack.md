# Note 7: Hallucination in an AI Attack

**Quotation:** “Claude [Anthropic’s AI model, which the attackers had tricked past its safety rules] didn’t always work perfectly. It occasionally hallucinated credentials or claimed to have extracted secret information that was in fact publicly-available. This remains an obstacle to fully autonomous cyberattacks” (Anthropic 2025, under “How the Cyberattack Worked”).

**Commentary:** In my first note collection, hallucination was a reason not to trust AI, and here it looks like good news for defenders.
I don’t think it helps them much, because the two sides can’t afford mistakes in the same way.
An attacker only needs one break-in, so a fake password just means trying again, and a human checks the results at one of the few decision points from note 6.
A defender checking thousands of systems needs every answer to be right, because one wrong “this server is patched” leaves a way in.
Anthropic says hallucination is an obstacle to “fully autonomous” attacks, but this attack didn’t need to be fully autonomous, since 80–90% was enough.
The NCSC also says skilled attackers “will need to remain in the loop” (National Cyber Security Centre 2025), but for attackers, that doesn’t cost much.

**Subject terms:** AI agents; hallucination; human oversight; offense–defense balance
