# Note 7: Hallucination in an AI Attack

**Quotation:** “Claude [Anthropic’s AI model, which the attackers had tricked past its safety rules] didn’t always work perfectly. It occasionally hallucinated credentials or claimed to have extracted secret information that was in fact publicly-available. This remains an obstacle to fully autonomous cyberattacks” (Anthropic 2025, under “How the Cyberattack Worked”).

**Commentary:** Hallucination was one of the main topics in my first note collection, where I saw it as a reason not to trust AI.
Here it shows up as a weakness in an attack, which at first sounds like good news for defenders.
I don’t think it helps them much, because attackers and defenders can’t afford mistakes in the same way.
An attacker only needs one break-in to work, so a fake password just means trying again, and a human checks the results at one of the few decision points from note 6.
A defender using AI to check thousands of systems needs every answer to be right, because one wrong “this server is patched” leaves a way in.
So the same problem is a small annoyance for attackers and a real risk for defenders.
Anthropic says hallucination is an obstacle to “fully autonomous” attacks, but the attack didn’t need to be fully autonomous, and 80–90% was enough.
The NCSC says something similar, that fully automated attacks are “unlikely to 2027” and that skilled attackers “will need to remain in the loop” (National Cyber Security Centre 2025).
But for attackers, staying in the loop doesn’t cost much.

**Subject terms:** AI agents; hallucination; human oversight; offense–defense balance
